## 实施顺序与边界

1. 写作流程：共享元数据校验，默认草稿，普通/教程/系列模板，只读发布检查；单元与构建测试后提交。
2. 技术内容：仅新增能力对应的标记/样式，不改变既有文章字号、宽度或组件布局；非公开 Markdown 样本置于 tests/fixtures，由测试请求拦截使用真实渲染管线，不增加生产路由或集合。
3. 移除进度条及无用计算；保留目录、返回顶部和原生转场。
4. 运行类型检查、静态构建、内容/输出验证、单元测试、Edge/WebKit 视觉与功能回归；尝试 Firefox，失败则如实记录。

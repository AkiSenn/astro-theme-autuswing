# 第三阶段：三端响应式重构

项目 `E:/autuswing-astro`，本地预览 http://127.0.0.1:4322/ 。本阶段实现导航与阅读区域的三套布局，沿用 AutuSwing 的森林绿、暖白、头像、日期图形和原生组件。路由、文章管理、SEO、搜索索引、评论标识保持独立于布局。

## 已实现的布局

| 可用 CSS 宽度 | 组件与行为                                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| ≥1000px       | `DesktopSidebar`：固定完整侧栏，保留头像、作者、站名、简介、核心导航、社交和工具；文章目录在导航下方独立滚动，不再用页签隐藏网站菜单 |
| 720–999px     | `TabletSidebar`：72px 图标栏，首页、归档、标签、友链、关于直接链接；搜索、外观、文章目录直接按钮；不依赖展开操作                     |
| <720px        | `MobileHeader` + `MobileNavigation`：顶部头像/品牌/搜索/外观，第二行直接导航；没有汉堡菜单、导航抽屉、多层页签或底部 Tab Bar         |

断点只读取视口 CSS 宽度，不判断设备名或横竖屏。导航从 `site.config.ts` 的一份数据派生，包含图标回退与当前页面状态；不显示的壳使用 `display:none`，不会进入 Tab 顺序。三套壳的工具共享一个搜索对话框、一份外观状态。

首页在平板模式使用容器查询：列表可用宽度 ≥660px 时双列，每列至少约320px；不足则单列。768px 实测单列，820px 实测双列；全文卡片模式强制单列。手机单列卡片将日期放到顶部，保留大日期个性并让标题与摘要获得完整宽度。

## 文章与目录

- 文章正文始终单列，最大704px；默认带边框卡片实测702px，外层留白随窗口调整。
- 手机文章由文章容器统一负责左右16px内距，移除旧布局的双层边距。320px 视口、预留15px滚动条时正文273px，390px时343px。
- 平板正文实测768px视口583px、820px视口635px；1024px完整侧栏下约626px，1280px以上稳定在702px。
- `ArticleContents` 在紧凑布局文章顶部提供独立目录按钮；滚动后也可由阅读工具打开。手机为底部目录面板，平板为居中面板，均只包含本文目录。
- 目录支持 Tab/Shift+Tab、Esc、遮罩关闭、焦点返回、点击章节后关闭并聚焦标题。手机锚点偏移读取实际顶栏高度，兼容导航换行。
- 搜索、目录、灯箱共用轻量的原生 dialog 打开函数，保持模态互斥；跨断点关闭目录，释放原生模态状态并恢复可见触发器的焦点。未添加导航状态框架。
- 关闭 JavaScript 时，核心导航仍直接可用，紧凑布局退回原生 details 目录；桌面目录保留。
- 社交、RSS在紧凑布局移入页脚。移除右下角重复的复制按钮，文章内原有复制/分享继续保留。
